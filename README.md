# Shimizu Tech Learning

AIを活用して業務改善アプリ・Webアプリを設計、実装、検証、納品できる実装者になるための学習リポジトリ。

## 目的

- DB設計を理解する
- APIの基本を理解する
- Webアプリの構造を理解する
- 検収条件を書けるようにする
- AIへの実装指示・レビュー指示を出せるようにする
- 小型業務アプリを作れるようにする

## 学習順序

1. DB設計
2. API基礎
3. Webアプリ全体像
4. 検収条件・テスト設計
5. AI開発指示・レビュー指示
6. 小型アプリ実装演習

## 運用ルール

- 学習ログを必ず残す
- 理解度を％で記録する
- 設計、実装、検収条件をセットで残す
- コードだけでなく「なぜそう作ったか」も残す
- Public中は実名企業名・社内情報・顧客情報を入れない
